# How to read **Ruby** documentation

[Ruby documentations](https://docs.ruby-lang.org/en/3.2/index.html)


- do some developers refer to documentations as API?
- what is API?
- is API an acronym for application programming interface?
- is it an overloaded term that refers to how applications talk to each other as well as documentation?
- what are the 3 you need to pay attention to?

1. class name / module name
2. class methods `::`
3. instance methods `#`
